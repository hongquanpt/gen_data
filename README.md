# Bài toán sinh dữ liệu giả 
## Cách thực hiện:
Sử dụng kĩ thuật bù nền Deepfill và tracking đối tượng bằng yolov9
## Những dạng dữ liệu được sinh ra:
### Dữ liệu về tốc độ:
Dữ liệu tăng lên đột ngột và dữ liệu tăng theo gia tốc ( Tăng dần sau đó chuyển động thẳng đều và chậm dần về vận tốc ban đầu)
Lệnh chạy: python all.py --input_folder xxx
### Dữ liệu về việc ngã:
Dữ liệu người bị ngã theo gia tốc trọng trường và momen lực
Lệnh chạy: python xoay1.py --input_folder xxx
